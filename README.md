# Simple AI Chatbot in C

## About
This is a beginner-friendly AI-style chatbot built using C language.

## Features
- Greeting responses
- Study motivation
- Programming jokes
- Date and time
- Help command
- Random replies

## Concepts Used
- Strings
- Arrays
- Functions
- Loops
- Conditions
- Random functions
- Time handling

## How to Run
gcc chatbot.c -o chatbot
chatbot.exe

## Sample Commands
hello
study
joke
time
help
bye

## Future Improvements
- Better conversational logic
- More commands
